# SpaceCadets
This repository is for the Space Cadets challenge for Southampton ECS students.

I will aim to keep my solutions short (relatively) and for once use comments properly.

---
### Challenge 1: Fetch any name using an email ID
Status: Complete

#### Main solution
The main solution is located in the `nameFromEmailID.py` file. I would like to think that, aside from the commenting, its relatively short and simple.

#### Fetch Url from name using google
This solution is in the `urlFromName.py` file. I had to use the Google Cloud Console API for this solution, as for some reason google really loves to captcha verify my HTTP requests.

#### Anagrams for any name
This solution is in the `anagramsFromName.py` file. It outputs all the anagrams as .txt file, as for the example word provided 'parliament' there are 4051 anagrams, and there are 30166 for my name.
